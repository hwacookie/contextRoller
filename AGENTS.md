# Project Instructions

## Language

All documentation and code documentation for this project must be written in **English only** — README, SPEC, comments, docstrings, error messages shown to users, and commit messages. No German (or other languages) in repo content.

## Spec Maintenance

When requirements or design elements are added to or removed from SPEC.md, the §8 Status checklist must be updated in the same change: new work items go into TODO; completed or removed items move to Done (or are deleted). The checklist must never drift out of sync with the spec.
